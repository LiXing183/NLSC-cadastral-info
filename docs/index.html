01 安裝與認識介面

先完成外掛安裝，再用下方模擬介面熟悉操作。

  1. QGIS →「外掛」→「管理與安裝外掛」→「從 ZIP 安裝」，選擇正式版 v2.0.0 安裝檔。
  2. 安裝後重新啟動 QGIS，啟用「NLSC地籍資訊查詢」，從工具列或外掛選單開啟。
  3. 縣市清單會預先載入；選好縣市後載入行政區，再載入地段清單。
① 查詢位置選縣市、行政區、段碼或地段名稱，輸入地號。
② 整理資料查看土地屬性、選取記錄及調整顏色。
③ 保存成果複製到試算表，生成向量後另存檔案。

03 查詢方式與結果

輸入地號半形逗號分隔多筆，例如 78, 78-1, 80。子號使用半形「-」。
點選圖面先加入地籍圖，再啟用點選模式，點在宗地內部。切換其他地圖工具即可停止。
定位與資訊優先填色與定位，再補齊屬性。有範圍時依範圍縮放，比例尺以 100 的倍數取整。
各頁籤提供哪些資訊？

土地：地號、面積、使用分區、使用地類別、權利人類別、公告地價及公告土地現值。
測繪資訊：地段測繪方式、日期與原始資料。
建物：有建號清單時顯示，選取建號後查詢明細。
公有土地：服務有提供時顯示所有權人、管理機關及資料日期。

「未提供」不一定代表失敗；服務可能沒有該欄資料。先看查詢狀態與錯誤提示。等待也包含 NLSC 回應與限流時間，不是固定每筆 0.5 秒。

04 選取、填色與排序

  1. 選取列：藍色底列供批次操作或複製。Ctrl 選不連續列，Shift 選連續範圍。實際外掛可雙擊列回看結果。
  2. 勾選填色：控制該筆宗地是否顯示填色，與選取列分開。
  3. 點擊色塊：若該列已在多選範圍內，顏色套用已選取列；否則只調整該筆。「預設填色」恢復跟隨共用顏色。
  4. 共用不透明度：所有宗地一致。0% 為全透明，100% 為不透明。預設 Cyan / 30%。

固定排序：未完成在前 → 填色顏色 → 縣市代碼 → 地政事務所代碼 → 段碼 → 地號主號與子號數值。例如 2、2-1、2-10、10。

地籍圖顏色控制地籍線與地號文字；填色顏色控制宗地遮罩。八種預設色只顯示英文名稱，自訂顏色顯示十六進位色號。

一般：排隊 / 查詢中 / 補齊資料紅色：已確認失敗橘色：整批結束後仍未完成

05 複製到 Excel

  1. 在「記錄」選取要輸出的列；沒有選取列時，複製全部記錄。
  2. 按「複製屬性資料」，切換 Excel，選起始儲存格，按 Ctrl + V。
  3. 每筆土地佔一列。多種權利人以「；」分隔，仍留在同一儲存格。

記錄頁複製 11 欄：縣市、行政區、段碼、地段、地號、面積、使用分區、使用地類別、權利人類別、公告地價、公告現值。排除填色、查詢時間及查詢狀態。

其他結果頁按相同按鈕，複製目前頁面的「欄位 / 內容」兩欄表格。

練習輸出預覽

先在練習介面查詢，再按「複製屬性資料」。

06 生成填色範圍

  1. 確認需要的土地都已勾選填色；取消不需納入的宗地。
  2. 按「生成範圍」。全部目前填色會融合為一個圖徵；藍色選取列不限制生成內容。
  3. 生成「填色範圍」暫存向量圖層，置於圖層清單最上方，使用預設紅色虛線樣式。
  4. 在 QGIS 右鍵圖層 →「匯出」→「另存圖徵…」，例如保存為 GeoPackage。

可在練習介面按「生成範圍」，觀察宗地內部邊界消失、外圍紅色虛線形成。

不相連的範圍可包含在同一多部分圖徵。所有已勾選填色均會納入，即使不透明度為 0%；確認範圍時建議調回可見的不透明度。

實際外掛輸出使用目前地圖座標系統。範圍由填色影像推算，精度受影像解析度限制；放大不會增加來源精度。暫存向量須匯出才能長期保存。

07 常見問題

HTTP 429 或等待時間變長？

NLSC 正在限流，外掛會依服務要求等待與重試。若已確定失敗，稍後重新查詢該地號。

沒有填色或無法生成範圍？

確認自動填色、記錄勾選方塊與不透明度。沒有取得填色影像的土地無法生成範圍。

關閉視窗或切換專案會如何？

背景生成會取消；關閉查詢視窗會停止未完成查詢並清除顯示填色。重開後可在本次使用的記錄重新勾選。

哪些資料需要自行保存？會有垃圾檔案嗎？

記錄與填色屬於本次使用資料。複製屬性到試算表，並匯出暫存向量。v2.0.0 填色與生成使用記憶體；公開選單快取有期限與容量限制，QGIS 圖磚與 Python 快取由系統管理。

要生成三筆已填色土地的全部範圍，需要先選取三筆資料列嗎？
